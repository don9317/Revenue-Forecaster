My Sport Space Revenue & Membership Intelligence Center v6.10

Changes from v6.9:
- Replaces the opaque rental pickup with a transparent calendar/run-rate extrapolation.
- Avoids double-counting future reservations already booked later in the selected month.
- Rental tiles now read: Booked/Actual Rental Revenue -> Calendar Extrapolation -> Forecast Rental Additions -> Total Forecast Rental Revenue.
- Calendar Extrapolation explains revenue through the As-of Date, expected remaining revenue, future rentals already booked, and the resulting unbooked projected pickup.
- Membership forecasting now exposes the Membership Forecast Baseline as selected-month active MRR from the Membership Snapshot before additions.
- Total Forecast Membership Revenue is explicitly baseline + forecast additions.
- Existing stream notes/comments and consolidated Forecast workflow are preserved.
