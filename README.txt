My Sport Space Revenue & Membership Intelligence Center v6.9
CURRENT MONTH + FORECAST NOTES

Changes from v6.8:
- Added a clear CURRENT MONTH FORECAST heading above the Overview forecast tiles.
- Overview explains that future-month forecasts are built in Rentals & Events and Memberships, then consolidated on Forecast.
- Final Projected Forecast tile moved to the end of the forecast tile sequence.
- Rentals & Events Monthly Forecast now includes a comment/note button beside each adjustment field:
  * Additional Rentals
  * Internal Bookings
  * Events / Registrations
  * Parties
- Notes are saved by month and revenue type using the existing forecast storage structure.
- System Rental/Event Baseline renamed System Forecast Baseline with an explanation of current-month vs future-month behavior.
- Existing forecasting calculations and data-source architecture otherwise preserved.

Use:
1. Open index.html in a modern browser.
2. Load the Reservation, Membership, and Stripe files in Admin / Data Sources.
3. Set Forecast Month and As-of Date.
4. Enter stream-level forecast additions in Rentals & Events and Memberships.
5. Click the note icon beside a Rentals & Events adjustment to document the reason.
6. Review consolidation and macro/final adjustments on Forecast.
7. Return to Overview for the current-month forecast and chart.
