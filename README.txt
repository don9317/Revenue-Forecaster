My Sport Space Revenue & Membership Intelligence Center v6.13

CHANGES IN v6.13
- Dollar adjustment fields now accept full free-form currency amounts (for example $20,000) and commit on Enter or when leaving the field.
- Added $ prefixes to dollar-entry fields in Rentals & Events, Membership MRR, and Final Management Adjustment.
- System Forecast Baseline info control now explains the baseline calculation; it can be clicked as well as hovered.
- Added a Breakdown control to each month on Consolidated Monthly Forecast showing Rentals & Events, Memberships, Operating Forecast, Overall Outlook dollars, and Final Management Adjustment.
- Updated Help / Tutorial documentation to reflect the current forecasting architecture, calendar extrapolation, data-source separation, recurring membership MRR, forecast consolidation, and Overview graph behavior.
- Preserves v6.12.1 import hotfix and membership source-integrity protections.

WORKFLOW
1. Open index.html in your browser.
2. Load Reservation CSV, Membership Snapshot CSV, then Stripe Balance History in Admin / Data Sources.
3. Build stream assumptions in Rentals & Events and Memberships.
4. Review consolidated results and macro/final adjustments in Forecast.
5. Validate the final dashed forecast on Overview.
